- 캐릭터: 윤나리 / Yoon Nari, S등급, 앰버 폭스 레이싱, 기계 정비·시스템 조정.
- 시안 원본: 대화에서 생성된 `a_detailed_sprite_sheet_illustration_on_a_transpar.png`.
- **이미지 원본 GitHub 업로드 상태: 미완료**. 이 문서는 시안의 프레임 구성과 제작 기준을 저장하는 것이며 PNG가 저장소에 있다고 주장하지 않는다.
- 비율: 기존 승인된 **일반 인체 비율의 애니메이션풍**. SD·치비·2.7등신 금지.

| 동작 | 시안 표기 | 게임 사용 목적 |
|---|---:|---|
| 대기 idle | 8 / 반복 | 피트 대기, 호흡·눈 깜빡임 |
| 호흡·휴식 | 6 / 반복 | 휴식 상태 |

- 방향별 원화: 정면·우측·후면·좌측. 방향별 이동 프레임은 별도 재검수 대상.
- 도구/이펙트: 휠건, 렌치, 노트북, 진단 태블릿, 타이어, 헤드셋, 공구함, 경고·성공 이펙트 등. **윤나리의 기계 정비 역할에 맞는 소품만 실제 작업에 적용**.
- **중요:** 생성된 이미지는 설명 글자와 배경이 포함된 **콘셉트 보드**로서 투명 PNG 아틀라스가 아니다. 실제 게임용으로 쓰려면 프레임 추출·투명화·피벗 통일·손/공구/발 접지·방향별 외형·루프 연속성 검증이 필요하다.
- 윤나리 기존 승인 원화와 얼굴·헤어·은색 머리핀 두 개·체형을 비교 검수한 뒤 마스터 에셋으로 채택한다. 시안이 자동으로 승인 원화를 대체하지 않는다.
