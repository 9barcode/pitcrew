## 필수 보존 원칙
- 승인된 가로형 인게임 UI의 구성과 미술 스타일을 변경하지 않는다.
- 레이스 상단 화면은 기존 UI 안에서 2D/2.5D 중계로 구현한다.
- 팀 유니폼은 일반 비율 캐릭터 전신/작업 프레임에 일체형으로 그린다.
- 메인 시안은 화면 구성과 미술 기준이다. 실제 게임용 배경·차량·캐릭터·UI 및 애니메이션 프레임은 별도로 제작한다.
- 차량의 구도·바퀴 비율은 현재 승인본을 유지한다. 고은채는 작업 쪽을 내려다보고 휠건을 타이어에서 거둔 준비 자세를 기준으로 한다.
