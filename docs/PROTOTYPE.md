# 피트크루 키우기 — 레이스·정비 연결 프로토타입

2026-11-07: 상단 자동 레이스와 중앙 정비를 연결하는 실행 코드 추가.

## 데이터 연결

`Race.cars`가 차량 누적 거리, 속도, 피트 상태, 정비 시간, 타이어 상태, 완주 시간을 소유한다. 중계와 미니맵은 동일한 `location(car)` 함수를 사용한다. 순위판과 결과는 `Race.order`를 사용한다.

본선 → 피트 진입 → 서비스 박스 정차 → 정비 → 피트 출구 → 본선 → 완주.

정비는 리프트 상승 / 병렬 타이어·점검 / 하강 / 안전 확인 단계로 표시한다. 현재 총 정비 시간은 시제품 고정값이며, 개별 캐릭터 능력치에 따른 작업 의존성 계산은 아직 구현하지 않았다.

## 검증

Node 테스트 6개: 6대 완주·의무 정비, 2초 지연에 따른 완주 시간 악화, 정비 차량 정지 중 경쟁 차량 진행, 실시간 순위와 누적 거리 일치, 진행 중 지연 추가 및 재시작 재현성.

## 제한

중앙 승인 이미지는 정적 참고 레이어로 사용한다. 실제 분리 프레임·수집/육성·저장·보상 지급·서버는 구현 범위에 포함하지 않는다. 상단 차량과 서킷은 임시 2D 운전자 시점 그림이며 주행 AI는 단순화되어 있다. 격차는 완주 전 거리/속도 추정치다.

## 필수 시각 기준 수정

- 상단은 운전자 1인칭 2D 중계. 3D 외부 시점 폐기.
- 상대 차량의 ID·팀명·색상·상대 거리를 실주행 정보에서 직접 참조.
- 추월/피추월 메시지의 상대 ID도 실제 거리 역전으로 생성.
- 같은 프레임의 위치로 중계·미니맵·순위판 갱신.
- 정비장 승인 이미지 전체 비율 유지, 잘림 금지.
- 동기화 테스트: 블루 코멧 실제 객체와 화면 대상 동일성 및 추월 이벤트 상대 ID 일치.
