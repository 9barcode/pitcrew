# 상단 가로칸 하이라이트 프로토타입

## 2026-11-07 확정 수정
- 중앙 정비크루 바로 위, 승인 시안의 기존 여러 레이싱카가 보이는 가로칸만 경기 중계로 사용.
- 1인칭 폐기. 별도 대형 중계 패널 폐기. 정비장 전체 시안 비율 유지.
- 일반 주행은 짧은 프레임 루프, 주요 순간은 측면 배틀·피트 진출입·결승선 카메라로 표시.
- 각 팀 전용 3프레임 생성 시트 사용. 임의 색상 차량 대체 금지.
- 배틀 상대 ID를 고정하고 실제 상대 거리를 화면상의 위치로 변환. 순위 역전과 미니맵은 동일 Race 상태에서 갱신.
- 피트로 인한 순위 변화는 추월 이벤트로 재생하지 않음.

## 검증
완주·정비·지연·실시간 순위·객체 동일성·배틀 대상 고정·피트/결승선 분리 테스트.

## 남은 작업
생성 차량 프레임 정합성 개선, 다양한 실제 카메라 각도의 차량 프레임 확장. 현재 각도는 측면 한 종류이며 여러 각도의 완성 중계 연출을 구현했다고 주장하지 않는다.

## 2026-11-08 중앙 정비장
앰버 폭스 5인 각 6프레임을 분리 적용했다. 레이스 상태와 연동하며 차체 뒤의 몸과 접촉 팔은 별도 순서로 합성한다. 상세 범위와 검증은 [GARAGE_ANIMATION.md](GARAGE_ANIMATION.md) 참고.
