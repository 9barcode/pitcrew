# 중앙 정비장 애니메이션 파일럿

## 제작 기준
승인 원본 `docs/concepts/approved-main-ui.png`의 전체 배치와 미술을 기준으로 생성했다. built-in 이미지 생성으로 빈 정비장 배경, 독립 차량, 5인 × 6프레임 시트를 제작했다. 올리비아 배경 잔여물은 별도 투명화 편집을 거쳤다. 시트 셀 3×2의 공통 알파 경계 사각형을 좌표 메타데이터로 기록하며 프레임별 크기 조정은 하지 않는다. Noto Sans KR 서브셋을 동봉했으며 라이선스는 `assets/fonts/OFL.txt`에 있다.

## 역할 / 상태
| 캐릭터 | 재생 내용 |
|---|---|
| 고은채 | 대기/깜빡임, 휠건 준비·체결·회수 |
| 레오 | 대기/깜빡임, 잭 핸들 상승·하강 작업 |
| 윤나리 | 대기/깜빡임, 계기 조정·손 회수 |
| 소피아 | 대기/깜빡임, 태블릿 확인·입력 |
| 올리비아 | 대기/깜빡임, 정지 신호·릴리스 |

`src/garage-scene.js`는 실제 `Race.player` 상태를 읽는다. 게임 속도는 작업 시간에 영향을 주지만 별도 시트의 FPS를 비정상적으로 높이지 않는다. 진입/출발 중 차량은 정비장 경로로 이동하고, 정비 중에는 차량 위치를 고정한다. `정비 시연` 버튼의 시작 위치는 검사 편의를 위한 경기 상태 설정이다.

## 가림 규칙
1. 원본 인물이 없는 빈 배경을 사용해 중복된 몸이 남지 않게 한다.
2. 뒤쪽 크루를 먼저 그린다. 차량의 차체 영역에 해당하는 뒤쪽 하체는 가림 영역으로 제외한다.
3. 차량, 고정 접지 그림자와 리프트 높이를 그린다.
4. 정비 중 윤나리의 실제 접촉 팔 범위만 다시 그려 차체 위에 놓는다.
5. 앞쪽 고은채·레오를 그린다.
6. 진행 바/하단 UI가 마지막에 표시된다. 모든 크루는 중앙 정비장 영역 안에서만 렌더링된다.

## 검증
- `npm test`: 기존 경기 10개 + 정비 단계/역할과 프레임 메타데이터 2개 통과.
- 실제 Chromium: 7단계 전환, 5인 시트/배경/차량 로드, 실제 정비 시연, 새 경기 초기화, 레이스 시작 버튼, 1700×1080 및 900×650. JS 오류/404 없음.
- 화면 검수에서 남은 올리비아 배경, 캐릭터 위치, 진행 바 덮임, 이름표/작은 화면 순위표 가림을 수정했다.
- `scripts/check-garage.cjs`: 실제 브라우저 검수. `scripts/render-garage.mjs`: Canvas 레이어 단독 렌더링이며 브라우저 전체 화면 검수와 구분한다.

## 미구현 / 주의
총 30프레임의 초기 파일럿이며 이동 등 모든 상태와 모든 캐릭터를 완성한 것이 아니다. 6프레임은 원화 재생으로 인한 작은 형태 변화가 남을 수 있다. 원본 시안의 픽셀 복제나 모든 화면 크기/기기에서 결함이 없다는 보장은 하지 않는다. 타이어 분리·운반, 인물 이동 경로, 모집/육성/저장 등은 후속 범위다. 화면 주변 일부 시안 메뉴/자원/초상 카드는 아직 정적 이미지다.

## 생성 프롬프트 요약
- 공통: 승인 시안의 성인 일반 비율·얼굴·헤어·앰버 폭스 유니폼·그림체 유지. 투명 배경, 3열×2행 동일 셀, 고정 발/무릎 피벗, 문자/차량/다른 사람 제외.
- 배경: 주변 UI는 유지하고 중앙 5인·차량·이름표만 제거해 빈 차고 복원.
- 차량: 중앙 #27 노랑/검정 오픈휠 차량만 같은 전방 사선 구도로 독립 제작.
- 각 인물: 위 표의 준비/작업/회수 동작 6프레임. 올리비아는 2차 배경 제거를 통해 알파 0 영역을 확보.
