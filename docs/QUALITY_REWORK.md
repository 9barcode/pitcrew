# 정비장 품질 재작업

기준: 승인된 일러스트형 정비장, 상단 작은 중계, 하단 5인 크루 카드 유지.

## 1. 공간과 가림
- 차량은 원본 이미지 종횡비를 유지한다. 기존 788×332 강제 변형 제거.
- 뒤쪽 인물 → 실제 알파 차량 → 앞쪽 인물 순서만 사용한다.
- 인물 하체를 사각형으로 지우거나 팔만 사각형으로 재합성하던 처리, 배경 조각으로 덮던 처리 제거.
- 5명의 크기와 바닥 위치를 다시 맞춘다.

## 후속 순서
1. 인물 시트의 반투명 배경을 제거한 원화로 교체하고 자세 연결 재설계.
2. 타이어/차체/잭 독립 에셋과 실제 작업 접점, 단계별 타임라인.
3. 정비 종료 후 손 회수/안전 신호/차량 출발 순서.
4. 이미지 속 UI를 실제 UI로 교체하고 이름표/중계 가독성 개선.

검증은 자동 테스트와 실제 브라우저 장면 캡처를 구분한다. 프레임 수나 테스트 통과만으로 미술 품질 완료를 판정하지 않는다.
