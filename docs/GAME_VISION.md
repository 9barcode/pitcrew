# 피트크루 키우기 (Pitcrew)

## 확정된 게임 방향
- 프로젝트명: **피트크루 키우기**
- GitHub: https://github.com/9barcode/pitcrew
- 장르: 5인 피트크루 수집·육성형 방치 RPG + 레이스 결과 시뮬레이션
- 목표: 신생 피트크루를 키워 세계 최고의 레이싱팀으로 성장. 경기 진행 중 피트인→정비→피트아웃에 소요된 시간이 실제 레이스 순위와 결과에 영향을 줌.
- 레퍼런스 UI: 사용자가 2026-11-06 승인한 가로형 정비장+레이스 중계 결합 시안. 게임 속 팀·차량 브랜딩은 추후 독자적으로 확정. F1/실제 팀 로고 사용 금지.

## 캐릭터·편성
- 총 **30명의 고유 정비사**, 등급 **SS / SA / S / A / B / C**, 등급별 5명.
- 동시에 출전하는 팀은 5인.
- 각 캐릭터 별 레벨 ★1~★5, **동일 캐릭터 동일 별 2장**을 합쳐 다음 별로 상승. 최대 ★5에는 기초 ★1 16장 필요. 등급 승급은 없음.
- 하위 등급은 초반 주력이며 상위 등급으로 점차 교체. 동일 별/육성 기준 상위 등급이 우세하도록 밸런싱.
- 공구도 SS~C 등급 및 ★1~★5, 동일 공구·동일 별 합성. 의상·고글·모자·장갑·신발 슬롯의 별도 성장 방식은 미확정.
- **윤나리 = S등급 ★1, 긴급 기계 점검·조정 전문** (기존 엔진·동력계 설정에서 피트크루 역할로 전환). 시작 지급 여부 미정.

## 윤나리: 작업 모드 분리 (필수)
1. **일반 피트스톱**: 차가 지정 위치에 멈춤 → 윤나리의 차량 상태 확인(계기/센서·외관 신속 확인), 제한적인 기계 점검과 필요한 경미한 조정 → 작업 완료 확인 후 릴리스 담당에게 인계. 불꽃·용접·대규모 분해는 연출하지 않음. 제한 시간과 팀 작업 동선 유지.
2. **긴급 정비/특수 이벤트**: 이상 증상 감지 → 고장 부위 진단 → 기계 부품 조정·교체 등의 별도 애니메이션. 용접 등 큰 수리는 일반 짧은 피트스톱이 아닌 안전한 정비 환경에서만 등장하도록 제한.
3. **공통 외형**: 기존 승인된 윤나리 원화와 얼굴·두 은색 머리핀·나른한 눈매·머리 모양·체형 일관성 유지. 기본 대기 자세는 곧게 서는 자세, 구부정한 자세는 보조 연출로만. 승인 원화의 자연스러운 인체 비율을 유지하고 얼굴 비례와 헤어 실루엣을 일치시킨다. SD·치비 변형 금지.

## 디자인 기준: 수집하고 싶은 일반 비율 캐릭터
- 승인 시안의 **세련된 레이싱 중계 + 정비장 3/4 시점 + 네이비/퍼플 중성 바탕, 앰버/옐로 포인트, 풍부한 조명** 유지.
- 전 캐릭터 **얼굴 실루엣/눈매/헤어/피부톤/표정/소품**이 멀리서도 구별되는 고유 디자인. 단, 동일한 세계관의 브러시 스타일·광원·윤곽선·인체 비율을 지킬 것.
- 희귀도는 **캐릭터 자체 미술의 품질 차이**가 아니라 카드 프레임·전용 애니메이션·이펙트·일러스트 배경의 희소성 차이로 표현. C~SS 모두 매력 있게 디자인.
- 기본 스프라이트: idle, walk/run, ready, job start, loop, finish, success, mistake, victory; 각 역할 고유 작업 동작 별도. 베이스 얼굴/체형을 프레임별로 재생성하지 말고 통일한 원본 디자인 기반.
- 카드 수집 UX: 전신 캐릭터가 중심인 카드, 등급과 별·전문 분야는 보조, 신규 획득 순간 실루엣→등장→전신·표정→고유 작업 모션 미리보기. 뽑기/도감은 원본 캐릭터 식별과 비교가 쉬워야 함.
- SS/SA는 눈길을 끄는 정비 연출과 프로필 이펙트가 있지만 가독성을 해치거나 게임 화면을 가리지 않음. 하위 등급 역시 독립적인 매력과 초반 성장 재미 보장.
- 캐릭터별 실루엣/얼굴 차별화: 단순 머리색 교체 금지. 성별, 연령감, 안경·귀마개·공구 방식, 작업 습관, 승리 포즈 등이 달라야 함. 윤나리의 기존 승인 원화는 변경하지 않음.

## 승인 시안 화면 구조
- 좌측 세로 메뉴, 상단 레이스 생중계/순위/랩, 중앙 5인 피트크루 액션, 우측 팀·다음 피트 작업, 하단 5인 수집 카드와 능력치·육성 버튼.
- **캐릭터를 화면의 주인공으로**: 차량은 작업 상황을 설명하는 역할, 정비사의 표정·손동작·동선이 읽히도록 작업 구역별 구도와 카메라 줌 사용. 작업 팝업은 캐릭터를 가리지 않을 것.
- 캐릭터 카드에는 고유 얼굴/전신 캐릭터, 희귀도, 별, 전문 분야를 구분해서 표기. 좌우 인물 구도와 메인 장면의 해당 캐릭터를 동일하게 매칭.
- 시안은 목표 미술 방향의 레퍼런스이며 **실제 구현/에셋 적용 완료를 의미하지 않음**.

## 게임 플레이 상의 조건
- 정비 작업의 병렬성과 순서를 모두 고려: 차량 정지→잭 올리기→타이어·점검 작업→잭 내리기→안전 확인→피트아웃.
- 전체 정차 시간은 단순한 5인 작업 시간의 합계가 아니며 선후행 조건 및 가장 늦은 병렬 작업의 완료시점에 좌우됨.
- 정비 실패/지연은 레이스에 영향을 주되 안전 사고를 희화화하지 않음. 스테이지 난도는 상대 팀 기록, 돌발 상황, 타이어/기계 상태, 전략 등으로 성장.
- 수치 밸런스, 30명 이름/스킬/최종 역할 배치, 캐릭터 획득 확률 등은 후속 설계 항목.


## 현실 모터스포츠 기반 레이싱 커리어 (기획안 2026-11-06)
### 원칙
- 현실의 레이싱 종류, 경기 방식, 예선/본선, 랩, 순위, 피트인/피트스톱/피트아웃, 시즌 포인트, 경기별 정비 규칙을 조사하여 참고한다.
- **실제 대회·팀의 고유명칭과 로고/리버리/공식 영상·음성·그래픽은 사용하지 않고 독자 제작한다.** 단순 명칭 교체만으로 모든 법적 위험이 없어지는 것은 아니므로 상표, 차량 디자인, 서킷, 규정 원문 복제 등 개별 검토.
- 모든 레이싱을 단일 실제 승급 체계라고 오인시키지 않는다. 포뮬러 경로는 드라이버 육성 경로를 게임 커리어에 각색한 것; GT·투어링·내구·전기 레이스는 별개 시리즈.
- 게임의 5인 편성은 플레이어가 관리하는 핵심 크루 단위이며 실제 종목별 전체 피트 인원과 동일하다는 뜻이 아니다.

### 경기 시스템
- 예선 랩타임 → 출발 그리드 → 본선(랩/시간) → 피트 레인 속도 제한 → 정비 → 안전 릴리스 → 피트아웃 → 경기 결과 → 시즌 포인트.
- 피트 작업 인원, 타이어 교체 의무, 급유, 드라이버 교대, 페널티 등은 **종목별 실제 규정을 확인한 후 별도 데이터**로 정의한다. 공통 규칙으로 뭉뚱그리지 않는다.
- 피트스톱 기록과 실수가 주행 시간·순위에 반영되며, 단순 정차 시간뿐 아니라 레이스 전략도 성장 요소로 활용한다.

## 캐릭터 제작 규격: 팀별 유니폼 일체형 전신 에셋 (기획안)
### 미술 방향
- 이전의 과장된 아동용 카툰 SD 대신 **세련된 반실사풍 애니메이션 일러스트 + 붓 터치 질감**을 채택. 작은 화면에서도 읽히는 얼굴/몸 비례는 유지하되, 눈·코·입의 과장, 지나친 데포르메, 획일적인 미소는 피한다.
- SD·치비·대두 비율을 채택하지 않으며 기존 승인 메인 시안의 자연스러운 전신 비율을 유지한다. 기존 승인한 인게임 시안의 광원, 깊이, 경기장/정비장 UI 분위기를 유지. 윤나리의 승인된 얼굴/두 은색 머리핀/나른한 눈매 등 고유 아이덴티티를 고정한다.
- **유니폼을 PNG 조각으로 잘라 몸 위에 붙이는 방식은 금지.** 팀 유니폼을 입은 상태로 각 캐릭터의 전신을 하나의 완성된 그림으로 제작해 옷 주름, 가림, 조명, 팔·손 연결을 일치시킨다.
- 동일 캐릭터가 팀을 바꾸어도 얼굴·체형·헤어·신체 비율은 변하지 않는다. 팀별 차이는 의복, 모자·고글·장갑·신발, 로고, 색상, 소품이며 얼굴 변형은 불허.

### 제작 단위
- **캐릭터 30명 × 확정 팀 6개 = 최대 180개의 팀별 전신 버전**. 팀 수 변경 시 동적으로 재산정. 예전 5팀 가정의 150개는 현 6팀 계획과 맞지 않으므로 폐기.
- 30명 각각: 고정 마스터 디자인(정면/측면/후면·색상/비례 가이드), 표정 세트, 역할·동작 정의.
- 팀별: 고정 유니폼 시트(전신 앞/뒤, 장갑·신발·모자·고글·엠블럼), 팀 색상 팔레트.
- 캐릭터×팀별: 일체형 전신 일러스트, idle 기준 프레임, 역할별 작업 애니메이션의 **완성형 전신 프레임**, 도감/카드용 일러스트.
- 작업 동작의 타이밍·포즈 설계·애니메이션 상태 머신은 공유 가능하나, 실제 표시되는 각 프레임은 팀별 복장에 맞는 통합 렌더링으로 검수.
- 필수 애니메이션 상태: idle, 이동, 작업 준비, 시작, 반복, 완료, 성공, 실수, 승리. 윤나리는 일반 피트스톱(상태 확인·경미한 조정)과 긴급 정비(진단·부품 조정/교체) 별도 시퀀스.
- 작업 프레임은 캐릭터 얼굴과 손, 옷, 공구가 자연스럽게 연결되는지 검수. 팔·손 개수, 발 방향, 관절, 접지, 배경 테두리, 프레임 간 크기/좌표 변화 검사.
- 카드/도감/메인 장면에서 **같은 인물·같은 팀 복장**을 사용하고, 등급별 프레임/효과만 차등 적용한다.

- 제작 순서: **윤나리 포함 5인 × 우선 1팀**으로 마스터 원화·동작·UI 검증 → 동일 5인에 다른 팀 유니폼 적용 → 검수 후 30인·전체 팀으로 확장.
- 팀 유니폼별 모든 프레임을 일괄 생산하기 전, 소수 파일럿으로 이미지 일관성·저장 용량·제작 비용을 검증한다.

## 팀 정체성과 성능의 분리 (확정 2026-11-06)
- 팀 이름, 엠블럼, 차고 테마, 차량 리버리, 팀별 유니폼은 **외형 및 소속감만** 결정한다.
- 팀 이름에 따른 고정 패시브(예: 블루 코멧 타이어 속도 +10%)는 **채택하지 않는다**. 이전에 제안된 팀별 능력 특성은 폐기.
- 레이스/피트스톱 성능은 **편성된 5명 정비사, 등급/별/레벨, 장비, 팀 시설, 기술 연구, 경기별 전략**으로 결정한다.
- 팀을 변경해도 동일 캐릭터의 고유 등급·별·레벨·개인 장비는 유지되지만, **시설·연구 진행도는 팀별로 독립 저장**된다. 팀 전환 시 선택 팀의 시설·연구 레벨만 적용되므로 실제 피트스톱 성능은 달라질 수 있다.
- 시설·연구는 **각 팀(team_id)에 귀속되는 별도 성장 시스템**이다. 다른 팀의 기술·시설 레벨을 공유하거나 자동 승계하지 않는다. 팀 이름 자체의 고정 능력 보너스는 없다.

## 팀 시설 육성 (초기 설계)
| 시설 | 핵심 효과 | 시각적 성장 |
| --- | --- | --- |
| 정비 작업대 | 기계 정비 효율 | 작업대·공구·리프트 설비 확장 |
| 타이어 스테이션 | 타이어 교체 효율 | 휠건·타이어 랙 확장 |

| 크루 훈련장 | 정비사 경험치 획득량 증가 | 연습장·훈련 장비 확장 |
| 기술 연구실 | 연구 단계 해금 및 연구 효율 | 분석 장비·연구 설비 확장 |
| 물류 창고 | 오프라인 보상 저장량 증가 | 부품 창고·보관 시설 확장 |

- 시설 레벨 업은 경기 보상 재화와 단계별 재료를 소비한다. 시설별 상한, 비용 곡선, 해금 시점은 밸런스 검증 후 결정.
- 시설 업그레이드 시 차고 배경/오브젝트도 단계적으로 변화한다. 업그레이드 전후 차이가 시각적으로 읽혀야 한다.
- 시설 효과는 현재 소속 팀의 시설 레벨만 적용한다. 다른 팀으로 전환하면 그 팀의 시설 상태를 불러오고, 이전 팀으로 돌아오면 이전 팀의 성장 상태를 복원한다.

| 연구 | 효과 | 선행 조건 예시 |
| --- | --- | --- |
| 고속 체결 기술 | 휠건 작업 시간 단축 | 타이어 스테이션 레벨 |
| 정밀 진단 기술 | 점검·진단 시간 단축 | 진단 센터 레벨 |

| 작업 동선 최적화 | 이동·준비 시간 단축 | 크루 훈련장 레벨 |

- 연구는 일반 피트스톱과 긴급 정비에 해당하는 작업만 개선한다. 현실 경기 규칙과 충돌하는 임의의 작업을 강제하지 않는다.

## 성장 밸런스·UI 원칙
- 캐릭터 수집·승급·장비가 주 성장 동기이며 시설·연구는 이를 보조하는 **장기 누적 성장**이다. 팀 이름 자체에 고정 능력 우열은 없지만, 팀별 시설·연구 투자 수준에 따라 성능 차이가 발생한다.
- 시설과 연구의 속도 증가 효과는 작업 단계별 적용 범위와 상한을 명시하고, 중복 곱연산 폭주·0초 정비·애니메이션 파손을 방지한다.
- 실제 작업 시간은 병렬 작업과 선후행 의존성을 반영해 계산한다. 표시된 전체 작업 속도 수치만 단순 합산하지 않는다.
- UI에는 '팀 관리 > 팀 정보 / 팀 시설 / 기술 연구'를 배치하고, 시설 선택 시 현재 레벨, 다음 레벨 효과, 비용, 해금 조건을 표시한다.
- 시설/연구 화면에도 승인된 정비장 시점과 **팀별 유니폼을 착용한 완성형 일반 비율 캐릭터의 프레임 애니메이션**을 사용한다. 캐릭터별 담당 위치에서 작업 루프를 반복하며, 옷 조각 오버레이는 사용하지 않는다.
- 팀 시설/연구 화면 시안은 컨셉 참고용이며 실제 UI나 이미지 에셋 구현을 의미하지 않는다.

## 팀별 성장 데이터 격리 (확정 2026-11-06)
- 시설 레벨, 연구 해금·레벨·진행 중 연구, 해당 팀의 기술 재화/연구 포인트는 **player_id + team_id** 단위로 저장한다.
- 팀 A에서 올린 타이어 스테이션 Lv.10과 연구 Lv.5는 팀 B에 전혀 적용되지 않는다. 팀 B는 자신의 레벨(신규 팀이면 기본 Lv.1/미해금)부터 성장한다.
- 팀 A로 복귀하면 팀 A의 기존 시설·연구·진행 상태가 그대로 복원된다. 전환은 리셋이나 데이터 삭제가 아니다.
- 경기 계산은 **현재 선택 팀의 시설·연구 데이터만** 조회한다. 캐릭터 개인 육성/장비의 팀 간 공유 여부는 별도 정책으로 관리하되, 현재 기본안은 개인 성장 유지다.
- 서버 데이터 예시: `player_team_progress(player_id, team_id, facility_levels, research_levels, research_queue, team_resources, updated_at)`. 실제 DB 스키마는 구현 시 정규화 여부를 검토한다.
- 팀 변경 시 UI 캐시도 team_id로 구분하여 이전 팀의 레벨·연구 효과가 잠깐이라도 표시되거나 적용되지 않도록 한다.
- 신규 팀 진입 시 해당 팀의 초기값을 생성하고, 팀 전환 및 복귀 시 각각의 성장 데이터를 불러오는 테스트가 필수다.
- UI는 선택한 팀 엠블럼·차고·유니폼과 함께 해당 팀의 시설/연구 현황만 표시한다. 팀별 진행도 비교 화면은 후속 기능.

### 밸런스·저장 원칙
- 팀 전용 연구의 **전체 피트스톱 시간 기여 목표는 약 3~5% 이내**. 실제 작업 단계의 적용 범위와 병렬 작업·선후행을 반영하며 명목 수치를 단순 합산하지 않는다.
- 실수 확률 감소는 퍼센트포인트가 아니라 **상대 감소율**이다. 예: 10%에서 상대 -12%는 8.8%.
- 특정 연구가 무효인 종목에서도 공통 시설/연구와 캐릭터 편성으로 경쟁할 수 있도록 종목별 평균 기록·실수율·승률을 검증한다.
- 팀 전환 시 이전 팀의 연구 보너스를 가져오지 않는다. 복귀하면 해당 팀에서 진행했던 시설·연구·재화 상태가 그대로 복원된다.
- 기존 **12팀 시스템 시안은 과거 콘셉트 참고용**으로만 보존한다. 실제 UI의 팀 선택·팀 수 표시는 6개 기준으로 변경한다. 승인된 메인 레이스/정비장 화면의 구도와 미술 스타일은 그대로 유지한다.

## 정비사 세부 능력치 체계 (확정 방향 2026-11-06)
- 기본 능력치 6종 + 전문 분야 5종 + 캐릭터별 고유 스킬 1개를 기본 구조로 채택. 아래 수치·공식은 밸런스 시뮬레이션 전 **예시**.
| 스탯 | 약어 | 의미 | 주요 영향 |
| --- | --- | --- | --- |
| 정비력 | PWR | 물리 작업 능력 | 부품·타이어 취급 속도 |
| 손기술 | DEX | 공구 조작 숙련 | 체결·정밀 작업 속도 |
| 판단력 | INT | 상황 분석 | 진단·고장 파악 속도 |
| 정확성 | ACC | 작업 정확도 | 작업 실패 확률 감소 |
| 집중력 | FOC | 반복 작업 안정성 | 연속 작업 시 효율 유지 |
| 협응력 | SYN | 팀 작업 조율 | 준비·전환·연계 효율 |
- 기본 LUK/MP는 두지 않는다. 확률적 발동은 고유 스킬로, 스킬 제어는 자동 발동·쿨타임으로 처리한다. 집중력은 별도 소모형 체력 게이지가 아닌 안정성 스탯.
- 전문 분야별 우선 스탯: 타이어 교체(DEX/PWR/ACC), 잭·리프트(PWR/ACC/SYN), 기계 점검(INT/DEX/ACC), 진단·전략(INT/FOC/SYN), 릴리스·안전(SYN/ACC/FOC).
- 동일 전문 분야라도 스탯 분포와 스킬을 다르게 설계해 수집의 의미를 만든다. 하위 등급의 상위 등급 역전이 상시 발생하지 않도록 동일 육성 기준 희귀도 우위를 유지.
- 예시 윤나리 S★1: PWR 65 / DEX 76 / INT 94 / ACC 88 / FOC 72 / SYN 80. **가상 비교값이며 최종 능력치가 아님**.
- 고유 스킬 예: 윤나리 '이상 징후 포착'(진단 시간 단축 확률 발동, 긴급 정비 진단 보너스), 타이어 전문가 '초고속 체결', 잭 전문가 '완벽한 지지'. 실제 확률·쿨타임·수치 미정.
- 성장 경로: 캐릭터 레벨은 기본 6종 스탯, 동일 캐릭터 ★합성은 능력치/스킬 강화, C~SS 등급은 기초값·성장 상한·스킬 성능, 장비는 능력치·작업 효율, 팀 시설/연구는 **현재 선택 팀만의 보조 효과**.
- 작업 시간 예시: `T = T_base / (1 + B_character + B_equipment + B_facility + B_research)` (B는 비율, 해당 작업에 유효한 효과만 포함). **가설 공식**이며 확정 전에 효율 상한·스탯 환산식·최소 작업 시간·반올림·확률 처리·작업 선후행 및 병렬 실행을 검증한다.
- 캐릭터 UI는 6종 스탯과 함께 담당 작업의 **예상 소요 시간 / 실수 확률**을 표시. 레이스 전체 정차 시간은 각 작업의 단순 합이 아닌 의존 관계로 계산.
- 인게임 프레임 애니메이션: 5명이 담당 구역에서 작업 시작→6~8프레임 정도의 작업 루프(초기 제안 8~12FPS)→작업 완료로 전환. 작업 진척에 맞춰 루프를 중지하고 각자 완료 모션 실행. 실제 프레임 수/FPS는 파일럿 검증 후 확정.
- 팀별 유니폼 일체형 일반 비율 전신 완성 프레임, 발 접지·관절·공구 위치·좌표 고정 검수. 작업 속도 수치가 바뀌어도 프레임이 부자연스럽게 초고속 재생되지 않도록 루프 횟수/완료 전환을 조절.

## 상단 소형 레이스 중계 화면 구현 (확정 방향 2026-11-06)
- **사용자가 승인한 기존 가로형 인게임 UI 구도는 변경하지 않는다.** 상단의 가로로 길고 높이가 낮은 레이싱 중계 영역만 독립된 2D/2.5D 애니메이션 컴포넌트로 구현한다. 좌측 서킷 미니맵, 중앙 5인 정비 장면, 우측 순위/피트 정보, 하단 카드 배치는 유지한다.
- 상단에 모든 장면을 동시에 넣지 않고, **한 번에 한 가지 중계 카메라 구도**만 보여준다. 소형 화면에서 차량 식별과 속도감을 우선하며 차량 2~4대 정도만 렌더링한다. 다른 참가 차량도 레이스 엔진에서 계속 시뮬레이션한다.
- 풀 3D 차량 물리 및 자유 카메라는 구현 범위에서 제외. 배경 일러스트(서킷·관중석·하늘·펜스)와 차량 방향별 투명 스프라이트를 **분리**해 원근 스케일·좌표 이동·패럴랙스·타이어 회전·차체 진동·모션 블러·속도선·음향으로 현장감을 만든다. 배경에 차량을 합친 단일 이미지는 금지.
- 최초 구현용 카메라 구도: **정면/사선 직선 질주, 측면 추월, 코너 진입·탈출, 피트 레인 진입/복귀**. 서킷당 우선 3~4개 구도를 준비하고, 필요한 이벤트 구도를 재사용한다.
- 중계 상태: (1) 평상시 주행 장면 루프 (2) 실제 추월/순위 변화 발생 시 2~3초 추월 장면 (3) 코너 구간 진입 시 코너 연출 (4) 피트인 시 진입 장면 (5) 피트스톱 동안 **다른 차량의 주행 장면** (6) 피트아웃 후 복귀 장면 (7) 마지막 랩/피니시 연출.
- 화면 연출은 실제 경기 데이터에 **종속**된다. 추월이 없는데 추월 장면을 보여주거나, 피트 정차 중인 플레이어 차량을 주행하는 것처럼 보여주지 않는다. 연출용 차량 위치·크기·카메라 이동은 시뮬레이션 결과를 시각화하는 값이며 경기 결과를 별도로 결정하지 않는다.
- **단일 레이스 시뮬레이션 상태**를 상단 중계, 기존 좌측 서킷 미니맵, 실시간 순위, 중앙 정비 애니메이션이 공유한다. 차량별 lap, trackProgress, speed, gap, raceTime, status(racing/pit_in/pit_stop/pit_out), 팀/차량 ID를 관리한다.
- 미니맵 차량 점은 같은 trackProgress와 랩·피트 상태를 반영하며, 피트 진입/정차/복귀 시 실제 피트 레인 경로를 따라간다. 사용자 차량은 강조색, 상대 차량은 식별 가능한 팀별 색으로 표시한다.
- **정비 화면 연계:** 차량이 피트에 도착하면 중앙 5명의 담당 구역 작업 루프가 시작되고, 잭 상승→병렬 작업→잭 하강→안전 확인 등 선후행을 지킨다. 상단에는 정비 중 다른 차량 주행을 보여준다. 정비 완료 후 피트아웃 장면을 보여주고 일반 중계로 돌아간다.
- 배속 x1/x2/x4 시 경기 시뮬레이션 시간과 차량 위치는 일관되게 증가시키되, 중앙 작업 프레임은 가독성을 위해 루프 횟수/상태 전환으로 조절한다. 지나친 초고속 프레임 재생 금지.
- 성능: 소형 중계 화면은 클리핑하여 보이는 스프라이트만 갱신하고, 화면 밖 차량 렌더링을 생략한다. 중앙 5인 애니메이션과 함께 모바일에서도 발열·메모리·FPS를 측정한다.
- **1차 프로토타입 검증 항목:** 직선 주행 루프 → 실제 추월 이벤트 연동 → 피트인/정비/피트아웃 연결 → 미니맵·순위 동기화 → 배속·저사양 기기 성능. 실제 게임 코드/애니메이션 에셋은 아직 제작되지 않았으며 본 항목은 구현 기획이다.
