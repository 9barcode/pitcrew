# 피트에서 정상까지 (Pitcrew)

## 확정된 게임 방향
- 프로젝트명: **피트에서 정상까지**
- GitHub: https://github.com/9barcode/pitcrew
- 장르: 5인 피트크루 수집·육성형 방치 RPG + 레이스 결과 시뮬레이션
- 목표: 신생 피트크루를 키워 세계 최고의 레이싱팀으로 성장. 경기 진행 중 피트인→정비→피트아웃에 소요된 시간이 실제 레이스 순위와 결과에 영향을 줌.
- 레퍼런스 UI: 사용자가 2026-11-06 승인한 가로형 정비장+레이스 중계 결합 시안. 게임 속 팀·차량 브랜딩은 추후 독자적으로 확정. F1/실제 팀 로고 사용 금지.

## 캐릭터·편성
- 총 **30명의 고유 SD 정비사**, 등급 **SS / SA / S / A / B / C**, 등급별 5명.
- 동시에 출전하는 팀은 5인.
- 각 캐릭터 별 레벨 ★1~★5, **동일 캐릭터 동일 별 2장**을 합쳐 다음 별로 상승. 최대 ★5에는 기초 ★1 16장 필요. 등급 승급은 없음.
- 하위 등급은 초반 주력이며 상위 등급으로 점차 교체. 동일 별/육성 기준 상위 등급이 우세하도록 밸런싱.
- 공구도 SS~C 등급 및 ★1~★5, 동일 공구·동일 별 합성. 의상·고글·모자·장갑·신발 슬롯의 별도 성장 방식은 미확정.
- **윤나리 = S등급 ★1, 긴급 기계 점검·조정 전문** (기존 엔진·동력계 설정에서 피트크루 역할로 전환). 시작 지급 여부 미정.

## 윤나리: 작업 모드 분리 (필수)
1. **일반 피트스톱**: 차가 지정 위치에 멈춤 → 윤나리의 차량 상태 확인(계기/센서·외관 신속 확인), 제한적인 기계 점검과 필요한 경미한 조정 → 작업 완료 확인 후 릴리스 담당에게 인계. 불꽃·용접·대규모 분해는 연출하지 않음. 제한 시간과 팀 작업 동선 유지.
2. **긴급 정비/특수 이벤트**: 이상 증상 감지 → 고장 부위 진단 → 기계 부품 조정·교체 등의 별도 애니메이션. 용접 등 큰 수리는 일반 짧은 피트스톱이 아닌 안전한 정비 환경에서만 등장하도록 제한.
3. **공통 외형**: 기존 승인된 윤나리 원화와 얼굴·두 은색 머리핀·나른한 눈매·머리 모양·체형 일관성 유지. 기본 대기 자세는 곧게 서는 자세, 구부정한 자세는 보조 연출로만. SD는 약 2.7등신, 얼굴 비례와 헤어 실루엣 일치.

## 디자인 기준: 수집하고 싶은 SD 캐릭터
- 승인 시안의 **세련된 레이싱 중계 + 정비장 3/4 시점 + 네이비/퍼플 중성 바탕, 앰버/옐로 포인트, 풍부한 조명** 유지.
- 전 캐릭터 **얼굴 실루엣/눈매/헤어/피부톤/표정/소품**이 멀리서도 구별되는 고유 디자인. 단, 동일한 세계관의 브러시 스타일·광원·윤곽선·SD 비율을 지킬 것.
- 희귀도는 **캐릭터 자체 미술의 품질 차이**가 아니라 카드 프레임·전용 애니메이션·이펙트·일러스트 배경의 희소성 차이로 표현. C~SS 모두 매력 있게 디자인.
- 기본 스프라이트: idle, walk/run, ready, job start, loop, finish, success, mistake, victory; 각 역할 고유 작업 동작 별도. 베이스 얼굴/체형을 프레임별로 재생성하지 말고 통일한 원본 디자인 기반.
- 카드 수집 UX: 전신 SD가 중심인 카드, 등급과 별·전문 분야는 보조, 신규 획득 순간 실루엣→등장→전신·표정→고유 작업 모션 미리보기. 뽑기/도감은 원본 캐릭터 식별과 비교가 쉬워야 함.
- SS/SA는 눈길을 끄는 정비 연출과 프로필 이펙트가 있지만 가독성을 해치거나 게임 화면을 가리지 않음. 하위 등급 역시 독립적인 매력과 초반 성장 재미 보장.
- 캐릭터별 실루엣/얼굴 차별화: 단순 머리색 교체 금지. 성별, 연령감, 안경·귀마개·공구 방식, 작업 습관, 승리 포즈 등이 달라야 함. 윤나리의 기존 승인 원화는 변경하지 않음.

## 승인 시안 화면 구조
- 좌측 세로 메뉴, 상단 레이스 생중계/순위/랩, 중앙 5인 피트크루 액션, 우측 팀·다음 피트 작업, 하단 5인 수집 카드와 능력치·육성 버튼.
- **캐릭터를 화면의 주인공으로**: 차량은 작업 상황을 설명하는 역할, SD 정비사의 표정·손동작·동선이 읽히도록 작업 구역별 구도와 카메라 줌 사용. 작업 팝업은 캐릭터를 가리지 않을 것.
- 캐릭터 카드에는 고유 얼굴/전신 SD, 희귀도, 별, 전문 분야를 구분해서 표기. 좌우 인물 구도와 메인 장면의 해당 캐릭터를 동일하게 매칭.
- 시안은 목표 미술 방향의 레퍼런스이며 **실제 구현/에셋 적용 완료를 의미하지 않음**.

## 게임 플레이 상의 조건
- 정비 작업의 병렬성과 순서를 모두 고려: 차량 정지→잭 올리기→타이어·점검 작업→잭 내리기→안전 확인→피트아웃.
- 전체 정차 시간은 단순한 5인 작업 시간의 합계가 아니며 선후행 조건 및 가장 늦은 병렬 작업의 완료시점에 좌우됨.
- 정비 실패/지연은 레이스에 영향을 주되 안전 사고를 희화화하지 않음. 스테이지 난도는 상대 팀 기록, 돌발 상황, 타이어/기계 상태, 전략 등으로 성장.
- 수치 밸런스, 30명 이름/스킬/최종 역할 배치, 캐릭터 획득 확률 등은 후속 설계 항목.


## 현실 모터스포츠 기반 레이싱 커리어 (기획안 2026-11-06)
### 원칙
- 현실의 레이싱 종류, 경기 방식, 예선/본선, 랩, 순위, 피트인/피트스톱/피트아웃, 시즌 포인트, 경기별 정비 규칙을 조사하여 참고한다.
- **실제 대회·팀의 고유명칭과 로고/리버리/공식 영상·음성·그래픽은 사용하지 않고 독자 제작한다.** 단순 명칭 교체만으로 모든 법적 위험이 없어지는 것은 아니므로 상표, 차량 디자인, 서킷, 규정 원문 복제 등 개별 검토.
- 모든 레이싱을 단일 실제 승급 체계라고 오인시키지 않는다. 포뮬러 경로는 드라이버 육성 경로를 게임 커리어에 각색한 것; GT·투어링·내구·전기 레이스는 별개 시리즈.
- 게임의 5인 편성은 플레이어가 관리하는 핵심 크루 단위이며 실제 종목별 전체 피트 인원과 동일하다는 뜻이 아니다.

### 경기 시스템
- 예선 랩타임 → 출발 그리드 → 본선(랩/시간) → 피트 레인 속도 제한 → 정비 → 안전 릴리스 → 피트아웃 → 경기 결과 → 시즌 포인트.

- 피트스톱 기록과 실수가 주행 시간·순위에 반영되며, 단순 정차 시간뿐 아니라 레이스 전략도 성장 요소로 활용한다.

## 캐릭터 제작 규격: 팀별 유니폼 일체형 전신 에셋 (기획안)
### 미술 방향
- 이전의 과장된 아동용 카툰 SD 대신 **세련된 반실사풍 애니메이션 일러스트 + 붓 터치 질감**을 채택. 작은 화면에서도 읽히는 얼굴/몸 비례는 유지하되, 눈·코·입의 과장, 지나친 데포르메, 획일적인 미소는 피한다.
- 기존 승인한 인게임 시안의 광원, 깊이, 경기장/정비장 UI 분위기를 유지. 윤나리의 승인된 얼굴/두 은색 머리핀/나른한 눈매 등 고유 아이덴티티를 고정한다.
- **유니폼을 PNG 조각으로 잘라 몸 위에 붙이는 방식은 금지.** 팀 유니폼을 입은 상태로 각 캐릭터의 전신을 하나의 완성된 그림으로 제작해 옷 주름, 가림, 조명, 팔·손 연결을 일치시킨다.
- 동일 캐릭터가 팀을 바꾸어도 얼굴·체형·헤어·신체 비율은 변하지 않는다. 팀별 차이는 의복, 모자·고글·장갑·신발, 로고, 색상, 소품이며 얼굴 변형은 불허.

### 제작 단위
- **캐릭터 30명 × 팀 6개(현재 가칭) = 최대 180개의 팀별 전신 버전**. 팀 수 변경 시 동적으로 재산정. 예전 5팀 가정의 150개는 현 6팀 계획과 맞지 않으므로 폐기.
- 30명 각각: 고정 마스터 디자인(정면/측면/후면·색상/비례 가이드), 표정 세트, 역할·동작 정의.
- 팀별: 고정 유니폼 시트(전신 앞/뒤, 장갑·신발·모자·고글·엠블럼), 팀 색상 팔레트.
- 캐릭터×팀별: 일체형 전신 일러스트, SD idle 기준 프레임, 역할별 작업 애니메이션의 **완성형 전신 프레임**, 도감/카드용 일러스트.
- 작업 동작의 타이밍·포즈 설계·애니메이션 상태 머신은 공유 가능하나, 실제 표시되는 각 프레임은 팀별 복장에 맞는 통합 렌더링으로 검수.
- 필수 애니메이션 상태: idle, 이동, 작업 준비, 시작, 반복, 완료, 성공, 실수, 승리. 윤나리는 일반 피트스톱(상태 확인·경미한 조정)과 긴급 정비(진단·부품 조정/교체) 별도 시퀀스.
- 작업 프레임은 캐릭터 얼굴과 손, 옷, 공구가 자연스럽게 연결되는지 검수. 팔·손 개수, 발 방향, 관절, 접지, 배경 테두리, 프레임 간 크기/좌표 변화 검사.
- 카드/도감/메인 장면에서 **같은 인물·같은 팀 복장**을 사용하고, 등급별 프레임/효과만 차등 적용한다.
