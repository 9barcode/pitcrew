# 피트크루 키우기

승인 시안의 중앙 정비장을 유지하고 **정비크루 바로 위의 가로 중계칸**에 2D 경기 하이라이트를 표시하는 플레이 프로토타입.

## 실행
Node.js 20 이상에서 `npm run dev` 후 http://localhost:5173 접속. 별도 패키지 설치 없음. `npm test`로 검증.

## 구현
- 6대 자동 주행, 3랩, 의무 피트 1회, 실제 정비 지연과 완주 순위 연결.
- 정비장 위 작은 가로칸만 중계에 사용. 1인칭·3D 외부 카메라 폐기.
- 팀별 생성 차량 측면 시트 6개와 사선 원화 6개. 팀 ID → 전용 이미지 경로를 고정하여 다른 팀 그림으로 대체하지 않음.
- 자동 하이라이트: 실제 근접 상대와 측면 배틀, 피트인/정비/피트아웃, 결승선. 평상시 선두 그룹 고정 카메라.
- 배틀 시작 시 상대 ID를 잠그고 두 차량의 실제 상대 거리로 앞뒤 위치를 표시. 순위 변경과 메시지는 실제 거리 역전 시점 기준.
- 순위·미니맵·중계는 같은 Race 객체를 같은 프레임에서 읽음.

## 현재 한계
중앙 정비장은 UI가 포함된 승인 시안 이미지이며 분리 캐릭터 프레임은 아직 미적용. 상단 차량 프레임은 생성 원화 기반 3프레임으로 크기·차체 모양에 약간의 편차가 있으며 완성형 애니메이션은 아님. 주행·추월 AI와 격차 계산은 단순화되어 있음. 서버·저장·모집·육성 미구현.

## 파일
`src/simulation.js`: 경기 상태. `src/highlights.js`: 카메라/대상 선택 및 팀 이미지 매핑. `src/renderer.js`: 차량 프레임 및 중계. `assets/cars/`: 생성 차량 시트.

## 중계 미술 개선
평면 스트라이프 배경을 코너 서킷 일러스트로 교체하고, 6팀 사선 원화·근접 추적 카메라·원근 크기·접지 그림자·부드러운 팬을 적용했다. 우측에 앰버 폭스 차량 이미지와 #27 AF-01을 복원했다. 참고 범위와 영상 버퍼링 제한은 `docs/BROADCAST_REFERENCE.md`에 기록했다.
