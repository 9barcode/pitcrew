# 피트크루 키우기

승인 시안의 상단 레이스와 중앙 피트 정비를 연결하는 첫 플레이 프로토타입.

## 실행

Node.js 20 이상에서 `npm run dev` 실행 후 http://localhost:5173 접속. 외부 패키지 설치 없이 실행된다. 검증은 `npm test`.

## 현재 플레이 범위

- 6대 자동 주행, 3랩, 모든 팀 의무 피트 1회, 완주 시간 기준 결과.
- 소프트웨어 3D 투영으로 그린 임시 서킷·차량과 우리 팀 추적/서킷 전체 카메라.
- 동일한 Race 데이터로 중계 위치·미니맵·순위·정비 상태·최종 결과 갱신.
- 피트 예약, 피트 감속, 정차, 정비, 합류. 경쟁 차량은 정비 중에도 계속 진행.
- 정비 지연 +2초 버튼으로 실제 정차 시간을 늘려 레이스 결과 비교.
- 정비 진행 단계와 5인 작업 진행률 표시. 일시정지, 1/2/4배속, 재시작.

## 미술 및 구현 범위

중앙 정비장은 기존 승인 시안의 정적 참고 이미지다. 캐릭터·차량을 분리한 실제 작업 프레임은 아직 적용하지 않았다. 이미지 속 기존 순위·문구는 참고 이미지의 일부이며 현재 레이스 데이터가 아니다. 실제 순위는 우측 실시간 순위판에 표시한다.

상단은 임시 박스형 차량을 사용하는 3D 좌표 기반 Canvas 렌더러다. 완성형 3D 차량 모델, 실차 물리, 충돌 판정, 정교한 추월/안전 합류, 실제 서킷 규칙은 후속 작업이다. 앞차 추종과 직선 구간 추월 경로는 단순화되어 있으며 완전한 레이싱 AI가 아니다.

`src/simulation.js`는 렌더링 없이 실행 가능한 고정 시간 간격 시뮬레이션이고, `src/renderer.js`는 이를 표시한다. `src/app.js`가 조작과 UI를 연결한다. 격차는 주행 거리와 속도로 계산한 추정치이며 완주 후에는 실제 완주 시간 차를 사용한다.
