# 피트크루 키우기

승인 시안의 중앙 정비장을 유지하고 **정비크루 바로 위의 가로 중계칸**에 2D 경기 하이라이트를 표시하는 플레이 프로토타입.

## 실행
Node.js 20 이상에서 `npm run dev` 후 http://localhost:5173 접속. 별도 패키지 설치 없음. `npm test`로 검증.

## 구현
- 6대 자동 주행, 3랩, 의무 피트 1회, 실제 정비 지연과 완주 순위 연결.
- 정비장 위 작은 가로칸만 중계에 사용. 1인칭·3D 외부 카메라 폐기.
- 팀별 생성 차량 측면 시트 6개와 사선 원화 6개. 팀 ID → 전용 이미지 경로를 고정하여 다른 팀 그림으로 대체하지 않음.
- 자동 하이라이트: 실제 근접 상대와 측면 배틀, 피트인/정비/피트아웃, 결승선. 평상시 선두 그룹 고정 카메라.
- 배틀 시작 시 상대 ID를 잠그고 두 차량의 실제 상대 거리로 앞뒤 위치를 표시. 순위 변경과 메시지는 실제 거리 역전 시점 기준.
- 순위·미니맵·중계는 같은 Race 객체를 같은 프레임에서 읽음.

## 현재 한계
중앙 정비장은 배경·차량·5인 크루를 분리하고 캐릭터별 6프레임을 적용했다. 각 상태는 이 파일 아래 정비장 구현 범위를 참고한다. 상단 차량 프레임은 생성 원화 기반 3프레임으로 크기·차체 모양에 약간의 편차가 있으며 완성형 애니메이션은 아님. 주행·추월 AI와 격차 계산은 단순화되어 있음. 서버·저장·모집·육성 미구현.

## 파일
`src/simulation.js`: 경기 상태. `src/highlights.js`: 카메라/대상 선택 및 팀 이미지 매핑. `src/renderer.js`: 차량 프레임 및 중계. `assets/cars/`: 생성 차량 시트.

## 중계 미술 개선
평면 스트라이프 배경을 코너 서킷 일러스트로 교체하고, 6팀 사선 원화·근접 추적 카메라·원근 크기·접지 그림자·부드러운 팬을 적용했다. 우측에 앰버 폭스 차량 이미지와 #27 AF-01을 복원했다. 참고 범위와 영상 버퍼링 제한은 `docs/BROADCAST_REFERENCE.md`에 기록했다.

## 추월 프레임 파일럿
앰버 폭스 / 블루 코멧 각 9프레임(접근 3·병주 3·이탈 3), 총 18프레임을 적용했다. `추월 시연` 버튼으로 1배속 경기 상태를 생성한다. 실제 거리 차로 각도를 고르고, 0을 통과할 때 실제 순위가 바뀐다. 다른 팀은 기존 원화 표시를 유지한다. 자세한 범위는 `docs/OVERTAKE_PILOT.md`.

## 중앙 정비장 프레임 구현 (2026-11-08)
- 승인 시안 원본은 보존하고, 인물과 차량을 제거한 정비장 배경을 별도 사용한다.
- 5명 각각 6프레임, 총 30프레임의 RGBA 시트와 프레임 좌표 JSON. 고은채 휠건, 레오 잭, 윤나리 계기 조정, 소피아 태블릿, 올리비아 정지/출발 신호.
- 같은 Race 상태의 준비 → 잭 상승 → 병렬 정비 → 잭 하강 → 릴리스 → 피트아웃에 연결한다. 재생 FPS는 경기 배속과 별도로 정해진다.
- 뒤쪽 크루 → 차량 → 윤나리 접촉 팔 → 앞쪽 크루 → 진행 UI 순서. 차량 아래의 뒤쪽 크루 몸이 틈으로 드러나지 않도록 가림 영역을 둔다.
- 상단 `정비 시연`은 실제 경기 객체를 피트 진입 직전으로 옮긴다. 하단 디버그에서 7단계를 선택하고 프레임을 정지/재생할 수 있다.
- `npm test`: 12개 통과. Playwright로 7단계, 정비 시연, 새 경기 초기화, 1700px/900px 화면을 확인했다. 선택적 브라우저 검수는 `node scripts/check-garage.cjs` (Playwright 및 Chromium 필요), 사용자 브라우저 경로는 `CHROMIUM_EXECUTABLE_PATH`로 지정.

### 범위와 한계
중앙 정비장 애니메이션 파일럿이다. 시안과 같은 구성/그림체를 따르지만 생성된 독립 원화는 원본의 픽셀 단위 복제가 아니다. 30명 전체/6팀 유니폼, 이동·모집·육성·장비·연구·재화·저장 시스템은 아직 미구현이며 주변 일부 메뉴/카드/재화는 시안 이미지다. 실제 타이어 탈착과 교체 타이어 별도 이동까지 구현한 것은 아니다. 완성 출시판으로 분류하지 않는다.
